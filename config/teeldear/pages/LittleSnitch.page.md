# Little Snitch

> Keyboard shortcuts for the Little Snitch connection alert.
> More information: <https://obdev.at/products/littlesnitch>.

- Toggle display of details:

`D`

- Toggle display of the Internet Access Policy:

`I`

- Toggle display of warnings:

`W`

- Cycle through warnings, IAP, details and notes:

`C`

- Select duration "Forever":

`1` or `F`

- Select the next duration:

`2` or `Right Arrow`

- Select the previous duration:

`3` or `Left Arrow`

- Select duration "For 1 Minute":

`0`

- Select duration "Until Quit":

`Q`

- Select duration "Until Restart":

`R`

- Select duration "Until Logout":

`L`

- Select duration "Once" (no rule is created):

`O` or hold `Shift`

- Select server condition "Any Connection":

`A`

- Select the previous server condition:

`Up Arrow`

- Select the next server condition:

`Down Arrow`

- Cycle through server conditions:

`S`

- Cycle through server condition name options:

`N`

- Toggle whether the rule is created in the active profile:

`P`

- Deny the connection:

`Esc` or `Option + Return` or `Command + .`

- Allow the connection:

`Return`

- Minimize the alert:

`Command + M`
